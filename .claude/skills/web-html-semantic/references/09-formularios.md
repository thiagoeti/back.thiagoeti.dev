# Formulários (Forms)

- `<form>`: Contêiner para envio de dados.
- `<label>`: Rótulo para campo de formulário.
- `<input>`: Campo de entrada (texto, número, checkbox etc).
- `<button>`: Botão clicável.
- `<select>`: Menu suspenso de opções.
- `<selectedcontent>`: Exibe a opção escolhida no select personalizável.
- `<datalist>`: Lista de sugestões para input.
- `<optgroup>`: Agrupa opções no select.
- `<option>`: Item de um select ou datalist.
- `<textarea>`: Área de texto multi-linha.
- `<output>`: Resultado de cálculo ou ação do usuário.
- `<progress>`: Barra de progresso.
- `<meter>`: Medidor (ex: uso de disco, votação).
- `<fieldset>`: Agrupa campos do formulário.
- `<legend>`: Título do fieldset.
