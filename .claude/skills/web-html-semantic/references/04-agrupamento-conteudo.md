# Agrupamento de Conteúdo (Grouping Content)

- `<p>`: Define um parágrafo de texto.
- `<hr>`: Linha horizontal de quebra temática.
- `<pre>`: Texto pré-formatado (mantém espaços e quebras).
- `<blockquote>`: Citação longa (em bloco).
- `<ol>`: Lista ordenada (numerada).
- `<ul>`: Lista não ordenada (com marcadores).
- `<menu>`: Lista de comandos (barra de ferramentas).
- `<li>`: Item de uma lista (ol, ul ou menu).
- `<dl>`: Lista de descrição (termo + definição).
- `<dt>`: Termo na lista de descrição.
- `<dd>`: Definição do termo na lista.
- `<figure>`: Agrupa conteúdo auto-contido (imagem, gráfico).
- `<figcaption>`: Legenda do elemento figure.
- `<div>`: Contêiner genérico para agrupamento.
