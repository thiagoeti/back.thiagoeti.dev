# Conteúdo Embutido (Embedded Content)

- `<picture>`: Contêiner de imagem responsiva (várias source + img).
- `<img>`: Insere uma imagem.
- `<iframe>`: Incorpora outro documento HTML.
- `<embed>`: Insere conteúdo externo (plugin, mídia).
- `<object>`: Incorpora objetos multimídia.
- `<video>`: Insere vídeo.
- `<audio>`: Insere áudio.
- `<source>`: Define múltiplas mídias para picture, video ou audio.
- `<track>`: Legendas ou faixas de texto para vídeo/áudio.
- `<canvas>`: Área para desenho via JavaScript.
- `<map>`: Define mapa de imagem clicável.
- `<area>`: Área clicável dentro de um mapa.
- `<svg>`: Gráficos vetoriais (SVG).
- `<math>`: Fórmulas matemáticas (MathML).
