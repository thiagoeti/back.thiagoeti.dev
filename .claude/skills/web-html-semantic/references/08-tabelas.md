# Tabelas (Tables)

- `<table>`: Cria uma tabela.
- `<caption>`: Título ou legenda da tabela.
- `<colgroup>`: Agrupa colunas para formatação.
- `<col>`: Define propriedades de uma coluna.
- `<thead>`: Grupo de linhas do cabeçalho.
- `<tbody>`: Grupo de linhas do corpo.
- `<tfoot>`: Grupo de linhas do rodapé.
- `<tr>`: Linha da tabela.
- `<th>`: Célula de cabeçalho de coluna ou linha (`scope="col|row"`).
- `<td>`: Célula de dados padrão.
