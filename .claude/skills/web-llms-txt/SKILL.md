# llms.txt

Índice curado em Markdown para o agente não rastejar HTML. Uso: inferência sob demanda.

## Regras

- Apesar do arquivo ser `.txt` o conteúdo dele é em Markdown.
- É um overview geral do projeto.
- O conteúdo deve ser o mais próximo possível do conteúdo real do projeto.
- Atualize sempre com as atualizações do projeto.
- Máximo 1k de linhas ou 3k tokens.

> Alguns projetos já tem o `/llms.txt` fixo, não precisa atualizar.
